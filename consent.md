# SMS Program Consent — Missed Rental Logging SMS Program

**Effective date:** January 1st 2026

This page documents how consent is obtained for the Missed Rental Logging SMS
program operated by Skye Equipment Rentals, LLC. This program is closed and
internal — it is not open to the public, and no member of the public can
enroll in it.

## Who can use this program

Only phone numbers belonging to Skye Equipment Rentals employees, explicitly
added by a company administrator to an internal authorized-sender list, can
send or receive messages through this program. Messages from any number not
on that list are not processed, not logged, and receive no automated reply.

## How consent is obtained

1. An employee is hired or assigned duties that include reporting missed
   equipment rental opportunities.
2. As part of onboarding for that role, the employee's manager or a company
   administrator explains the program to the employee directly, provides
   this program's [Privacy Policy](./privacy-policy.md) and
   [Terms and Conditions](./terms-and-conditions.md), and confirms the
   employee agrees to use the program as part of their job duties.
3. Only after this confirmation does the administrator add the employee's
   phone number to the authorized-sender list. Adding a number to this list
   is the technical gate that activates the program for that employee — no
   number is added without the onboarding step above having occurred.
4. The employee can begin sending messages once their number is authorized.

## Opting out

At any time, an employee may:
- Reply **STOP** to the program number to be unsubscribed immediately (the
  system enforces this automatically), or
- Ask their administrator to remove their number from the authorized-sender
  list.

Replying **START** re-subscribes a previously opted-out number. Replying
**HELP** returns program support contact information.

## Why this program does not use a public web opt-in form

This is not a consumer-facing or marketing program, and there is no public
sign-up flow to enroll — enrollment is entirely internal, tied to employment
and administered by Skye Equipment Rentals staff, as described above.
