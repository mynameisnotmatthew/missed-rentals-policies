# SMS Program Consent — Missed Rental Logging SMS Program

**Effective date:** January 1st 2026

This page documents how consent is obtained for the Missed Rental Logging SMS
program operated by Skye Equipment Rentals, LLC. This program is closed and
internal — it is not open to the public, and no member of the public can
enroll in it.

## Who can use this program

Only phone numbers belonging to Skye Equipment Rentals employees, explicitly
added by a company administrator to an internal authorized-sender allow-list,
are eligible to use this program. Messages from any number not on that list
are not processed, not logged, and receive no automated reply. Being on the
allow-list makes a number *eligible* — it does not by itself opt the number
in (see below).

## Opt-in path 1: Text-to-Join (primary opt-in method)

1. An employee is hired or assigned duties that include reporting missed
   equipment rental opportunities. As part of onboarding, a manager or
   administrator explains the program, provides this program's
   [Privacy Policy](./privacy-policy.md) and
   [Terms and Conditions](./terms-and-conditions.md), and adds the
   employee's phone number to the authorized-sender allow-list.
2. To actually opt in, the employee must personally text the keyword
   **JOIN** to the program number from their own phone.
3. On receiving JOIN from an eligible number, the system replies with a
   one-time confirmation message containing the required disclosures:

   > "Skye Equipment Rentals: You're opted in to the Missed Rental Logging
   > program to report missed equipment rentals by text. Msg frequency
   > varies. Msg & data rates may apply. Reply HELP for help, STOP to
   > cancel."

4. Only after this JOIN message is received is the number treated as
   opted in. Any other message sent by an eligible-but-not-yet-joined
   number is not processed as program data — the system instead replies
   asking the employee to text JOIN first. This JOIN text is the sole
   consent event recorded by the system; enrollment on the allow-list
   alone never activates the program for a number.

## Opt-in path 2: START keyword (re-subscription)

An employee who has previously opted in (via JOIN) and later replied STOP
may resume the program at any time by replying **START**. Because they
already completed the JOIN opt-in previously, START does not require
repeating it. Replying START to a number that was never opted in via JOIN
has no effect beyond clearing any opt-out flag — the program remains
inactive for that number until JOIN is sent.

## Opting out

At any time, an employee may reply **STOP** to the program number to be
unsubscribed immediately (enforced automatically by the system), or ask
their administrator to remove their number from the authorized-sender
list. Replying **HELP** returns program support contact information.

## Required disclosures

Every opt-in confirmation and opt-in prompt sent by this program includes:
program/brand name, program description, message frequency ("varies"),
"Msg & data rates may apply," and instructions to reply HELP for help or
STOP to cancel.

## Why this program does not use a public web opt-in form

This is not a consumer-facing or marketing program, and there is no public
sign-up flow to enroll — eligibility is tied to employment and
administered by Skye Equipment Rentals staff, but the actual opt-in action
is always taken by the employee themselves via the JOIN keyword described
above.
